# How a URL Works

### 1. URL
You enter a **URL** in the browser.

### 2. DNS Lookup
**DNS** changes the domain name into an **IP address**.

### 3. Connection
The browser creates a secure connection with the **web server**.

### 4. HTTP Request
The browser asks the server for the **web page**.

### 5. Web Server
The server processes the request and retrieves **data** if needed.

### 6. HTTP Response
The server sends **HTML**, **CSS**, **JavaScript**, and **images** to the browser.

### 7. Browser Rendering
The browser builds the page and displays it on your **screen**.
